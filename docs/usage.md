# 使用指南

本页介绍 WebClash 的功能与日常操作。部署与构建方式见 [安装与部署](installation.md)。

## 功能说明

### 仪表盘

- **系统负载**：主机 CPU 使用率与核数、系统内存占用、1 / 5 / 15 分钟负载均值（容器内为宿主机视角）。
- **实时状态**：上下行速率、会话累计流量、活动连接数、内核内存。
- **24 小时流量图**：1 分钟粒度上下行双曲线，Y 轴自适应 B/s、KB/s、MB/s 单位，鼠标悬浮可查看任意时间点的上传 / 下载速率。
- **内核状态**：运行状态、PID、运行时长、二进制路径、内置 / 外部内核标识，支持启动、停止、重启。
- **当前订阅**：名称、类型（订阅 / 本地）、更新时间；订阅提供 userinfo 时展示已用流量、总量与到期时间，可一键更新订阅。
- **最近日志**：最近 12 行 mihomo 标准输出，可跳转完整日志页。

### 代理组

- 按策略组展示节点，支持 Selector、URLTest、Fallback、LoadBalance、Relay、Smart 等组类型与当前选中节点。
- Selector 组点击即可切换节点；支持单节点延迟测速与整组测速，延迟按档位着色。
- 支持搜索、折叠策略组、手动刷新，数据每 4 秒自动刷新。

### 订阅与配置

- 支持 **URL 订阅**（http/https，可带 `#名称` 片段）与**本地 YAML** 导入；YAML 需包含 `proxies` / `proxy-providers` / `rules` 之一。
- 每个订阅独立设置：自动更新间隔（0–720 小时）、测速地址、测速超时（1000–60000 毫秒）与扩展规则。
- 一键激活订阅：生成 `data/kernel/config.yaml`，内核运行中时热重载生效。
- 更新订阅、全部更新、重命名、删除、直接编辑 YAML 原文。
- 解析订阅返回的 `subscription-userinfo`，在仪表盘展示流量配额与到期时间。

### 规则与规则集

- **规则**：按顺序展示规则类型、内容、策略；支持按类型 / 内容 / 策略搜索。
- **规则集**：展示 `rule-providers` 的类型、behavior、规则数、载入方式（inline / file / http）与更新时间。
- 规则集内容预览：在线查看规则内容，支持关键字过滤、复制全部、下载导出。
- **扩展规则**：在「规则」页追加自定义 mihomo 规则，支持「全局」（所有订阅）与「当前订阅」两种作用域；也可在订阅设置弹窗中单独编辑。
- 扩展规则插入在订阅自带规则之前，最终顺序为「当前订阅扩展规则 → 全局扩展规则 → 订阅规则 → MATCH」。每行一条，空行与 `#` 注释会被忽略；规则类型需大写，且不支持 `MATCH`（会屏蔽后续规则）。重复规则会在保存时自动去重，只保留首次出现。
- 策略需使用 `DIRECT`、`REJECT` 等内置策略，或当前订阅中实际存在的代理组 / 节点名称。保存时会校验策略是否存在；不存在时会返回具体错误（指出第几条规则和哪个策略），不会写入配置或重启内核。
- 编辑弹窗提供「规则示例」，覆盖域名、IP、GEO、规则集、端口、进程等常用语法并附中文说明；点击示例条目或复制按钮即可复制规则。
- 保存扩展规则后，内核运行中会热重载（失败回退重启），内核未运行则仅落盘；订阅刷新、自动更新与切换订阅都不会清除扩展规则。

### 连接

- **活跃连接**：WebSocket 实时流（约 1 秒刷新），展示目标、来源进程、规则、链路、网络类型、上下行流量与时长。
- **已关闭连接**：面板以 1 秒快照差分记录关闭的连接，默认保留最近 3000 条（可在设置中调至 100–20000），重启面板后清空。
- **IP 归属**：可选开启，按「源归属 → 目标归属」展示源 IP 与目标 IP 的国家 / 省 / 市 / 运营商（ip2region）或国家 / 地区（mmdb），国家名前显示 SVG 国旗图标，完全离线查询；回环 / 内网源地址显示为「本机」/「局域网」。
- 支持跨主机、IP、规则、链路、归属的搜索；单条关闭与一键关闭全部（需确认）。

### 日志

- 通过 WebSocket 实时接收 mihomo 日志，支持 debug / info / warning / error 级别筛选。
- 关键字过滤、暂停 / 继续接收、自动滚动开关、导出日志文件、清空当前视图。

### 设置

- **网络与端口**：运行模式（rule / global / direct）、混合端口、HTTP / SOCKS 端口（`0` 表示不单独监听）、日志级别、IPv6、允许局域网、绑定地址、WebUI 端口与监听地址。
- **端口认证**：为混合端口与 HTTP / SOCKS 端口统一设置用户名 / 密码（对应 mihomo 全局 `authentication`），支持多组用户；留空表示所有端口免认证。认证对本面板生成的端口生效，订阅自带且未配置 `users` 的监听同样会继承。
- **控制器**：mihomo external-controller 端口与密钥，支持一键重新生成密钥（会重启内核）。
- **TUN**：开关、自动路由、自动选择网卡、协议栈（gvisor / system / mixed）、DNS 劫持地址。
- **DNS**：覆盖订阅中的 DNS 配置，支持 fake-ip / redir-host、监听地址、fake-ip 网段、主 / 回退 / 默认 DNS（支持 DoH / DoT）。
- **IP 归属**：数据源选择、检查新版本、更新离线数据库、查看数据库状态与文件信息。
- **连接历史**：保留条数（100–20000）。
- **内核管理**：内核版本（`latest` 或 `vX.Y.Z`）、下载加速站（常用选项或自定义前缀，默认不设置）、自定义内核路径、随面板自动启动、缺内核时自动下载、下载进度与取消。
- **安全**：修改 WebUI 管理密码。
- **外观**：右上角可在深色 / 浅色主题间切换，选择保存在浏览器本地；首次访问跟随系统偏好。

### 内核管理

- 自动下载 / 更新 mihomo 内核（自动匹配 linux / darwin 与 amd64 / arm64 资产），下载复用下载加速站加速。
- 启动等待控制器就绪（最长 30 秒）；异常退出后 3 秒自动拉起，1 分钟内最多 5 次，超限停止拉起并记录原因。
- 启动前准备 Geo 数据（`geoip.dat` / `geosite.dat`），下载失败不阻塞启动，自动降级配置。
- 支持使用面板下载的内核、自定义路径的内核或系统 `PATH` 中的 `mihomo`。

### 安全

- 首次启动生成随机管理密码，写入日志与 `initial-password.txt`；密码使用 scrypt 哈希存储。
- 会话使用 HMAC 签名的 HttpOnly Cookie；登录接口有失败限速。
- 除健康检查与登录接口外，所有 API 与 WebSocket 均要求已登录。
- mihomo 控制器仅绑定 `127.0.0.1`，外部无法直接访问。
- 开启「允许局域网连接」时，建议在「网络与端口」配置端口认证，否则同网络内的任何人都可以使用代理。

## 使用指南

### 1. 登录与修改密码

首次启动的随机密码可以从启动日志或数据目录下的 `initial-password.txt` 获取（Docker 中为 `/data/initial-password.txt`，内嵌单文件可用 `webclash password -d <数据目录>` 查看）。登录后在「设置 - 安全」修改密码；忘记密码时可删除 `settings.json` 中的 `auth.passwordHash` 后重启，面板会重新生成初始密码。

### 2. 添加与激活订阅

1. 进入「订阅」页，点击「添加配置」：选择 URL 订阅（可带 `#名称` 片段）或粘贴本地 YAML。
2. 添加后在订阅卡片上点击「激活」，面板生成 mihomo 配置并热重载；仪表盘「当前订阅」会显示该订阅。
3. 打开某订阅的「订阅与测速设置」，可设置自动更新间隔、测速地址与超时；自动更新开启后会按间隔在后台拉取并刷新配置。
4. 需要临时改动配置时，可直接「编辑 YAML」保存，源订阅更新会覆盖手工改动。

### 3. 代理组与测速

「代理组」页展示当前配置的全部策略组。Selector 组点击节点即切换；节点右侧延迟可单独测速，组头「测速」按钮会测试整组。测速使用该订阅配置的测速地址与超时。

### 4. 规则与规则集排查

「规则」页按生效顺序列出规则与策略，适合确认某个请求命中了哪条规则；「规则集」页可查看每个 `rule-provider` 的载入方式与规则数，点击可在线预览内容并过滤、复制或下载。

### 5. 连接排查与 IP 归属

「连接」页分「活跃」与「已关闭」两个视图。已关闭连接由面板按秒差分记录在内存中，适合排查短连接。开启「设置 - IP 归属」并下载数据库后，连接表会以「源归属 → 目标归属」显示源 IP 与目标 IP 的国家 / 省市 / 运营商（离线查询，IP 不外发）；ip2region 数据源包含 IPv4 与 IPv6，国家名前显示 SVG 国旗图标。源地址为回环或内网地址时分别显示「本机」/「局域网」。

### 6. 仪表盘指标说明

- 「系统负载」为面板所在主机视角：裸机即本机；Docker 中容器共享宿主机内核，显示的是**宿主机** CPU / 内存 / 负载。
- 「内核内存」来自 mihomo `/memory` 接口自报的 `inuse`（Go 堆内存），面板仅透传展示；mihomo 的 `oslimit` 恒为 0，因此卡片只显示占用值。
- 流量图为最近 24 小时、1 分钟一桶的平均速率；内核停止或面板重启造成的空洞会断线显示，鼠标悬浮可读取具体时间点数值。

### 7. 日志

「日志」页实时接收内核输出。级别下拉框控制订阅级别；暂停后仍可在已有日志中过滤、导出；「自动滚动」可固定在底部跟随最新日志。

### 8. TUN 与 DNS

TUN 需要 root / `CAP_NET_ADMIN` 与 `/dev/net/tun`（Docker 需按 [安装与部署](installation.md#tun-模式) 映射）。面板生成的配置会覆盖订阅中的 DNS 段：默认开启 DNS、fake-ip 模式与 `198.18.0.1/16` 网段，可按需修改监听地址与上游。修改端口、TUN、DNS 等设置后需要保存并应用，涉及控制器的修改会重启内核。

### 9. 内核版本与更新

「设置 - 内核管理」可选择 `latest` 或指定版本（如 `v1.19.34`），也可填写自定义内核路径或使用系统 `PATH` 中的 mihomo。下载会显示阶段与进度，可取消；受限网络可在「下载加速站」中选择常用加速站或填写自定义前缀（默认不设置，直连失败后自动回退公共加速）。内核崩溃后面板自动拉起，短时间内连续崩溃会停止拉起并在日志中给出原因。

### 10. 备份与迁移

停止面板后拷贝整个数据目录（Docker 为命名卷 `webclash-data`）即可完成备份。其中 `settings.json` 包含密码哈希与会话密钥，`profiles/` 保存订阅原文；`bin/mihomo`、`kernel/`、`geoip/` 属于可重新下载的缓存，可按需排除。

## 运行时数据

- `data/settings.json`：面板设置（含密码哈希、会话密钥与全局扩展规则）
- `data/profiles.json`：订阅元数据（名称、类型、自动更新参数、扩展规则、激活项）
- `data/profiles/`：订阅 / 本地配置原文
- `data/kernel/config.yaml`：每次激活配置时生成的 mihomo 配置
- `data/kernel/geoip.dat`、`data/kernel/geosite.dat`：内核 Geo 数据
- `data/geoip/`：IP 归属离线数据库（开启 IP 归属后下载）
- `data/bin/mihomo`：面板下载的内核二进制
- `data/initial-password.txt`：首次启动生成的管理密码

## Geo 数据与 IP 归属

**内核 Geo 数据**：`geoip.dat` / `geosite.dat` 在启动前按镜像链（自定义镜像 → gh 代理 → jsDelivr → 直连 GitHub）运行时下载，**不内嵌**于二进制。下载失败**不会阻塞内核启动**：面板自动降级（删除引用缺失数据的 GEOSITE/GEOIP 规则与 DNS 项，回退 `MATCH,DIRECT`），并在「日志」与 `lastConfigError` 中保留警告。配置恒设 `geodata-mode:true`、`geo-auto-update:false`，mihomo 不再自行联网下载 geo。

**IP 归属**：面板功能，与内核 Geo 数据相互独立。开启后从镜像下载 ip2region（IPv4 + IPv6，含省市 / 运营商）或 mmdb（国家 / 地区）数据库到 `data/geoip/`，查询完全离线，仅用于连接页展示。

## 常见问题

**忘记密码**：删除 `data/settings.json` 中的 `auth.passwordHash`（Docker 中为 `/data/settings.json`）后重启，会重新生成初始密码。

**内核启动失败**：查看面板「日志」页或 `docker compose logs webclash`。常见原因：配置不合法、DNS 监听冲突、权限不足等。启动阶段的端口冲突会自动顺延（见下一条）；面板会在失败后自动重试，短时间内多次失败会停止拉起。

**端口被占用会自动换端口吗**：会。启动时会探测 WebUI 与内核端口（mixed / HTTP / SOCKS / 控制器 / DNS），被占用或与其他监听端口重复时自动顺延到下一个空闲端口，并在控制台打印改用后的端口。调整结果会写回 `settings.json` 并体现在生成的 `kernel/config.yaml` 中；WebUI 端口仅在未通过 `WEBUI_PORT`（或 `-p`）显式指定时写回设置，显式指定时本次运行改用新端口、环境变量保持不变。

**内核内存显示几十 MB，能降低吗**：该数值是 mihomo 自报的 Go 堆占用，面板不持有这部分内存。mihomo 默认使用保守的 Geo 加载策略，剩余部分主要是 Go 运行时与配置 / 规则对象基线；面板侧已采用类型化 JSON 解码、有界的历史 / 流量 / 日志缓冲来降低自身开销，不会随流量增长而膨胀。

**系统负载显示的是宿主机数据**：Docker 容器共享宿主机内核，CPU / 内存 / 负载均为宿主机视角，属预期行为。

**已关闭连接重启后消失**：连接历史保存在面板内存中（默认 3000 条），重启面板即清空，属于设计行为，可在设置中调整保留条数。

**系统安全软件拦截可执行文件**：部分终端的 EDR 会拦截直接运行新下载的二进制（面板、内核均可能触发）。可将 `webclash` 与 `data/bin/mihomo` 加入安全软件白名单，或改用 Docker 部署。

**订阅更新失败**：确认容器 / 主机可访问订阅地址；可在「设置 - 内核管理」的「下载加速站」选择常用加速站或自定义前缀。

**Geo 下载失败**：受限网络下 geo 镜像可能全部不可达，此时内核仍会启动并自动降级（见「Geo 数据与 IP 归属」）。可在「设置 - 内核管理」选择常用或自定义下载加速站，或手动把 `geoip.dat` / `geosite.dat` 放入 `data/kernel/`。

**WebUI 端口修改后没有生效**：WebUI 端口与监听地址需要重启 WebClash 进程才会生效；代理端口、TUN、DNS 等修改会在保存并应用后重启内核生效。

## 安全说明

- 面板面向管理员，请勿直接暴露到公网；如需远程访问，建议置于反向代理并启用 HTTPS。
- 控制器端口 `9090` 只监听 `127.0.0.1`，不随 WebUI 暴露。
- TUN 模式需要额外权限，仅在可信环境中开启。
- 数据目录中的 `settings.json` 含密码哈希与会话密钥，请妥善保管备份文件。
